**Об'єктна модель Python: протоколи, `property`, декоратори, контекстні менеджери.**

Бібліотека класів для предметної області «служба таксі» (варіант 8). Проєкт демонструє свідоме застосування «магічних» методів та механізмів об'єктної моделі Python: незмінні об'єкти-значення, валідацію через `property`, протоколи послідовності й ітерування, перевантаження операторів, параметризовані декоратори та контекстні менеджери.

---

## Модель предметної області

| Рівень | Клас | Опис |
|---|---|---|
| Об'єкт-значення | `GeoPoint(lat, lon)` | Незмінна географічна координата |
| Доменна сутність | `Ride(ride_id, rider, distance_km, fare, rating)` | Поїздка з валідацією полів |
| Колекція | `Fleet` | Набір поїздок з протоколами доступу, обходу та запитів |

### Обмеження полів `Ride`

| Поле | Правило |
|---|---|
| `ride_id` | шаблон `R-<число>`, наприклад `R-1001`; лише читання |
| `rider` | непорожній рядок |
| `distance_km` | число `> 0` |
| `fare` | число `> 0` |
| `rating` | ціле число від `1` до `5` |

### Критерії запиту `Fleet`

| Критерій | Тип | Приклад |
|---|---|---|
| `min_rating` | діапазонний (`rating >= значення`) | `fleet(min_rating=4)` |
| `rider` | за рівністю | `fleet(rider="Іван")` |

Критерії можна комбінувати: `fleet(min_rating=4, rider="Іван")`. Невідомий критерій → `TypeError` з переліком допустимих.

| № | Тема | Де реалізовано | Ключові механізми |
|---|---|---|---|
| 1 | Незмінний об'єкт-значення | `values.py` | `__slots__`, `__setattr__`, `__repr__`/`__str__`, `__eq__`, `__lt__`, `@total_ordering`, `__hash__`, `@dataclass(frozen=True, slots=True)` |

## Ключові проєктні рішення

- **Незмінність `GeoPoint`.** Поля виставляються через `object.__setattr__`, після чого встановлюється прапорець `_frozen`; перевизначений `__setattr__` після цього відхиляє будь-яке присвоєння з `AttributeError`. `__slots__` забороняє додавання нових атрибутів.
- **Узгодженість `__eq__` і `__hash__`.** Обидва методи спираються на один і той самий кортеж полів `(lat, lon)`, тому з `a == b` випливає `hash(a) == hash(b)`.
- **`NotImplemented` замість винятків.** Оператори порівняння та арифметики повертають `NotImplemented` для чужих типів, і Python сам підіймає `TypeError` (або пробує віддзеркалений метод).
- **Арифметика `GeoPoint`.** `+` і `−` трактуються як зсув координат, `* число` як масштабування. Результат проходить валідацію діапазону (`lat ∈ [-90, 90]`, `lon ∈ [-180, 180]`), інакше виникає доменний `ValueError`.
- **`ride_id`.** Умова варіанта не містить ідентифікатора, але протоколи колекції (`in`, `get`, дедуплікація в `+`) його потребують, тому поле додано до `Ride`.
- **`sum()` над колекціями.** `sum` починає з цілого `0`, тому `Fleet.__radd__` при `other == 0` повертає копію колекції, а в інших випадках делегує до `__add__`.
- **EAFP у `Fleet.get()`.** Спершу спроба `self._index[ride_id]`, потім перехоплення `KeyError` і підняття доменного `EntityNotFound` (`from None` ховає внутрішній ланцюжок винятків).
- **Відкат у `DispatchSession`.** `__enter__` зберігає `deepcopy`-знімок; при винятку `__exit__` відновлює стан *на місці* (посилання на `fleet` у користувача не змінюється) і повертає `False`, щоб виняток не приховувався.

## Що показує `demo.py`

Кожне завдання виводиться в консоль окремим розділом:

1. **Завдання 1** — `a is b` → `False`, `a == b` → `True`; використання в `set` і як ключа `dict`; `sorted`; перехоплені `AttributeError`.
2. **Завдання 2** — коректна поїздка; по одному некоректному значенню для кожного обмеження (у конструкторі й при присвоєнні); `from_dict`; `is_valid_ride_id`.
3. **Завдання 3** — `len`, індекс, зріз (тип результату `Fleet`, а не `list`), `in`, `for`; `pages(2)` з неповною останньою сторінкою; запити через `__call__`; `get` існуючого й відсутнього id.
4. **Завдання 4** — `f1 + f2`, `sum([f1, f2, f3])`, `f1 + 5` → `TypeError`; арифметика `GeoPoint` з обох боків; `min`, `max`, `sorted`.
5. **Завдання 5** — коректний виклик і порушення кожного правила (`positive`, `non_empty`, `one_of`); `Fleet.add_ride.__name__ == "add_ride"`.
6. **Завдання 6** — успішний сеанс, сеанс із винятком (стан до й після однаковий, виняток долітає до місця виклику), відкат часткових змін.

## Приклад використання

```python
from taxi import Fleet, GeoPoint, DispatchSession

fleet = Fleet()
fleet.add_ride(ride_id="R-1001", rider="Іван", distance_km=5.2, fare=120, rating=5)
fleet.add_ride(ride_id="R-1002", rider="Марія", distance_km=12.0, fare=300, rating=4)

top = fleet(min_rating=5)          # новий Fleet, відфільтрований за рейтингом
print(len(top), fleet.get("R-1002"))

with DispatchSession(fleet) as session:
    session.add_ride(ride_id="R-1003", rider="Олена", distance_km=3, fare=80, rating=3)
    # виняток тут відкотить усі зміни всередині блоку

kyiv = GeoPoint(50.45, 30.52)
print(kyiv, repr(kyiv * 1))        # 50.45°N, 30.52°E
```
